# INDÍGENA — Webby Wahine Website Preview

**Status:** Preview only, not approved for production.

## Open locally
Unzip and double-click `index.html`. All pages use relative links, so they also work on GitHub Pages or Cloudflare Pages.
For VS Code: File > Open Folder > select this folder; use a local preview extension or `python3 -m http.server 8000`, then open http://localhost:8000.

## Deploy preview to Cloudflare Pages
Upload this folder's contents to a private/unindexed preview deployment or connect a GitHub repository with no build command and `/` as output directory.
Do not connect a production domain until the client approves launch content, legal pages and booking.

## Included
11 HTML pages; `DESIGN.md`; CSS; JS; original client logo (unaltered); `robots.txt` (preview noindex).

## Required before launch
- Approve design, logo placement, typography and proposed copper accent.
- Replace decorative placeholder panels with approved real photography.
- Verify all program descriptions, pricing, credentials and health-related claims.
- Add approved scheduling provider and test booking end to end.
- Replace legal-page placeholders with reviewed policies; confirm privacy handling.
- Self-host actual licensed font files and remove Google Fonts dependency if preferred.
- Add canonical metadata, social sharing image, sitemap, robots production settings, favicon, and production domain.
- Audit responsive design, contrast, keyboard behavior, links, Lighthouse/PageSpeed, and security headers.
- Keep health intake off general public email/contact forms.

No client testimonials or appointment links have been fabricated.
