## Visual system
Original client-supplied logo preserved unchanged as `assets/indigena-original-logo.png`.
The original contains a photographic ivory background; no fake transparent recreation.
Colors: warm ivory #F7F4EC, oat beige #E8DFD0, muted blush #D8B8AD,
soft sage #A8B29C, deep olive #414B3B, warm charcoal #30332D,
proposed copper accent #A66F52 (client approval pending).
Typography: Mulish Medium for headings/navigation; Source Serif 4 Regular for body/editorial.
CSS requests these font families with system fallbacks. Production should self-host licensed OFL font files after verification.
Composition: generous whitespace, asymmetrical editorial columns, oversized headings,
quiet borders, typographic rhythm, restrained color, organic CSS textures, no generic card walls.
Motion: gentle reveal only where useful, respect prefers-reduced-motion.
Photography: NO stock or fabricated personal imagery. Marked photo areas are placeholders awaiting real client assets.
